# LongFunctionDetect
**Автор:** Волков Николай Игоревич  
**Группа:** М3111 

Лабораторная работа № 3. Расширение для VS Code, которое по нажатию
розовой кнопки `(ﾉ◕ヮ◕)ﾉ*:･ﾟ✧` в нижней строке состояния подсвечивает функции
текущего файла C++ длиной **больше 40 строк**.

## Возможности

- Проверяет функции, методы и конструкторы, которые распознало расширение C/C++.
- Считает физические строки от начала сигнатуры до конца диапазона функции
  включительно. Пустые строки, комментарии и строки со скобками учитываются.
- Функцию ровно из 40 строк не подсвечивает; из 41 строки уже подсвечивает.
- Выделяет весь диапазон светло-розовым фоном и ставит розовую метку на полосе
  прокрутки. При наведении на выделение показывает длину функции.
- Показывает количество найденных длинных функций.
- Снимает старую подсветку после редактирования. Для новой проверки нужно ещё
  раз нажать кнопку.
- Работает с текущим документом, включая несохранённые изменения.
  Весь проект автоматически не сканирует и код не изменяет.



## Установка готового VSIX

1. Откройте Extensions (`Ctrl+Shift+X`) → меню `...` → **Install from VSIX**.
2. Выберите `long-function-detect-1.0.0.vsix` и перезагрузите окно, если VS Code попросит.
3. Откройте файл C++ в доверенной папке и нажмите кнопку.


## Структура

| Файл | Назначение |
| --- | --- |
| `src/analyzer.cpp` | Подсчёт длины и сравнение с 40 |
| `src/extension.js` | Кнопка, список функций, запуск C++, подсветка |
| `scripts/build.js` | Сборка C++ без сторонних модулей Node.js |
| `package.json` | Команда, точка входа, активация и зависимость C/C++ |
| `.vscode/launch.json` | Запуск расширения по F5 |
| `.vscode/tasks.json` | Сборка перед запуском |
