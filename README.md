# LongFunctionDetect
**Автор:** Волков Николай Игоревич  
**Группа:** М3111 

Лабораторная работа № 3. Расширение для VS Code, которое по нажатию
розовой кнопки `(ﾉ◕ヮ◕)ﾉ*:･ﾟ✧` в нижней строке состояния подсвечивает функции
текущего файла C++ длиной **больше 40 строк**.

## Возможности

- Считает физические строки от начала сигнатуры до конца диапазона функции
  включительно. Пустые строки, комментарии и строки со скобками учитываются.
- Функцию ровно из 40 строк не подсвечивает; из 41 строки уже подсвечивает.
- Выделяет весь диапазон светло-розовым фоном и ставит розовую метку на полосе
  прокрутки. При наведении на выделение показывает длину функции.
- Показывает количество найденных длинных функций.
- Снимает старую подсветку после редактирования. Для новой проверки нужно ещё
  раз нажать кнопку.
- Работает с текущим файлом с++, включая несохранённые изменения.

## Основные файлы

| Файл | Назначение |
|---|---|
| `src/extension.ts` | Взаимодействие с VS Code, компиляция и запуск анализатора, подсветка функций |
| `src/analyzer.cpp` | Поиск функций C++ и подсчёт количества строк |
| `esbuild.js` | Сборка TypeScript в JavaScript |
| `package.json` | Настройки расширения |

## Запуск

Для работы необходимы Node.js, npm и компилятор `g++`.

Установить необходимые библиотеки:

```bash
npm install
```

Собрать расширение:

```bash
npm run compile
```

Нажать F5 для запуска в режиме отладки.

В открывшемся окне VS Code открыть C++-файл и нажать розовую кнопку.

## Упаковка

```bash
npm run package
```

После упаковки расширение можно установить через **Extensions → Install from VSIX**.

## Ограничения

Анализатор использует упрощённое распознавание функций C++. Некоторые сложные конструкции могут распознаваться неточно.
